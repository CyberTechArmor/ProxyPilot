# Public navigation within the selected runner

Scope W1–W6: explicit public mode, screened public resources/redirects, measured
readiness and protected inventory, focused frontend, independent review/CI, fixed
application/runtime delivery and real live proof. The legacy demo is unchanged.

Public runs have execution_mode=public_navigation and genuinely NULL guide and
consent pins. Existing runs/pins and dependent tables/triggers survive migration
1123. Model, private artifacts/clipboard, takeover/authentication and internal
policy grants are refused. The mode makes the initial configured origin a launch
seed; additional public GET/HEAD/empty OPTIONS destinations are screened before
contact. Existing closed-origin agent policy remains unchanged. DNS sets containing
private/protected/nonpublic answers are refused, sockets use pinned numeric targets
and peer readback, TLS remains verified, and cookies/bearer/session headers are
omitted. WebSockets, writes/POST, private sign-in and files remain unavailable.
Some sites relying on those transports or cookie sessions will not work.

Readiness checks installed and loaded helper hashes, the VM/fence boundary,
Chromium managed policy, gateway profile and live/TURN prerequisites. Active status
uses only the active boundary check; idle guest checks are not run during execution.
The fixed package stores protected hosts/addresses in its root-private install
journal and generation backups. A root-private expiring inventory plan caches DNS
measurement across review/apply without treating it as runtime acceptance.

The ordinary update delivers source and preserves installed runtime. The fixed
runtime installer must then update the runner; no Incus-upgrade flag is added.

Validation: public/legacy selected service/runtime tests, public destination and
capability cases, DNS-plan stability, historical migration preservation, actual
Chromium redirect/resource composition in disposable CI, frontend build and review.
Local socket restrictions and absent Chromium are retained limitations. CI, merge,
deployment and real live acceptance remain pending; see browser-delivery tracker.
